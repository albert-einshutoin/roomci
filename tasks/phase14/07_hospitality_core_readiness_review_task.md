# Task 07 — Hospitality Core Readiness Review

## Goal

Run a strict review to decide whether `roomci` now reads as a focused hospitality-like smart-home QA contract emulator rather than a broad, unfocused technology checklist.

## Review Questions

- Does the product clearly cover the core QA journey?
- Are reported technologies classified honestly?
- Does the product avoid implying private NOT A HOTEL compatibility?
- Are core flows stronger than broad protocol name-dropping?
- Would a hospitality/building-automation evaluator know what to run first?
- Would a generic IoT/SmartHome evaluator still understand the reusable core?

## Acceptance Criteria

- Review produces a readiness score and top blockers.
- Any unsupported technology claim is removed, weakened, or moved to future profile.
- Next implementation work is prioritized around evaluator value, not stack breadth.
