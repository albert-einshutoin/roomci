# Phase 22 Goal: Deferred Editor Authoring Assets

Phase 22 completes the editor-assisted authoring work intentionally deferred
from Phase 20.

## Completion Definition

- local VSCode assets exist under `tools/vscode-roomci/`
- scenario YAML schema associations are documented
- snippets cover common scenario, MQTT, Modbus, BMS, comfort, and assertion
  blocks
- tasks reference existing `roomci` and `make` commands
- assets are validated locally without marketplace publishing

## Explicit Non-Goals

- VSCode Marketplace publishing
- language server implementation
- graphical debugger implementation
