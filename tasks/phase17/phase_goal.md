# Phase 17 Goal: Promoted Contract Depth

## Goal

Implement only the Phase 16 roadmap items that improve deterministic local/CI evaluation without turning `roomci` into a vendor emulator or full protocol stack.

## Product Outcome

- Hospitality evaluators get safer intercom/relay and control-panel fault coverage.
- Building-automation evaluators get clearer BMS and comfort contract depth.
- External developers get small adapter sample clients.

## Non-Goals

- Full BACnet, KNX, Matter, OPC UA, Zigbee, or Thread runtime implementation.
- Real unlock authorization.
- Vendor/cloud/observability platform emulation.
