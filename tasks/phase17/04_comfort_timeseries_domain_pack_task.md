# Task 04: Comfort Time-Series Domain Pack

## Why

Comfort automation exists, but HVAC/sensor evaluators need deterministic sensor-zone replay and clear comfort-impact evidence.

## Acceptance Criteria

- Add a domain-pack profile for time-series temperature, humidity, occupancy, ceiling-zone, and living-zone readings.
- Keep the input format deterministic and fixture-based.
- Report oscillation, override safety, and guest comfort impact.
- Add examples and runner tests.

## Out of Scope

- Firmware, PCB, sensor hardware, or thermal engineering simulation.
