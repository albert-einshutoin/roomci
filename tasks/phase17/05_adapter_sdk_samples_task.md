# Task 05: Adapter SDK Samples

## Why

External teams need low-friction examples for mapping their private contracts into `roomci` without adding a second runtime.

## Acceptance Criteria

- Add small Go and TypeScript sample clients that drive the existing HTTP/MQTT/Modbus surfaces.
- Keep samples focused on adapter contracts, localhost, and CI evaluation.
- Add docs-only pseudocode for Lua-like automation hooks unless a real hook API is introduced.
- Include commands in the evaluator guide.

## Out of Scope

- A new SDK runtime.
- Vendor-specific clients.
