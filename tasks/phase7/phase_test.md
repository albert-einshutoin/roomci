# Phase 7 Test Plan

## Quality Gates

- Crate and public-API documentation coverage.
- Workspace test count and coverage thresholds.
- CLI ergonomics regression tests (multi-scenario, verbose, quiet, dry-run).
- CI quality-gate workflow parity (fmt, clippy, tarpaulin).
- README, schema, and docs index freshness.

## Done Means

Phase 7 is done when documentation, tests, CLI ergonomics, and CI quality gates meet production-grade thresholds and the canonical docs tree is the single source of truth.
