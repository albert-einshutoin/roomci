# Task 02 — Profile Import and Export Flow

## Objective

Provide a practical import/export workflow for profile metadata.

## Implementation Scope

- Add CLI or adapter command for export.
- Add CLI or adapter command for import validation.
- Add examples for supported device types.
- Add docs describing non-goals and compatibility limits.

## Acceptance Criteria

- Export works for lock, light, climate, sensor, and cover devices.
- Import validation can reject unsupported clusters.
- Docs explicitly state this is Matter-like profile handling, not full Matter.
