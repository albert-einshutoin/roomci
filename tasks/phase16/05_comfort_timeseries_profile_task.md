# Task 05: Comfort Time-Series Profile

## Why

Comfort automation exists, but docs mention future real time-series replay and sensor-zone assumptions. This could add value for HVAC and smart-home QA if kept deterministic.

## Acceptance Criteria

- Define report evidence for oscillation, override safety, and guest comfort impact.
