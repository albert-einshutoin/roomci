# Phase 18 Goal: Release-Candidate Sample And Evidence Hardening

Phase 18 should not add broad new emulator scope.

Goal:

- Make the newly added adapter samples mechanically verifiable.
- Tie Phase 17 domain-pack claims to machine-checkable evidence.
- Refresh public readiness scorecards so release-candidate claims match the current code.

Non-goals:

- No new vendor emulators.
- No full protocol conformance claims.
- No real lock, electrical safety, cloud, or BMS side effects.
