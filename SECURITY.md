# Security reporting

If you suspect a vulnerability in roomci, do not post exploit details,
credentials, private keys, personal information, customer configurations, or
confidential logs in a public issue or pull request.

As of 2026-09-28, GitHub private vulnerability reporting is disabled for this
repository, and maintainers have not designated a verified public security
contact. The former address in CONTRIBUTING was only a placeholder and is
not a reporting channel. A maintainer must designate and verify a private
reporting route before vulnerability details can be received privately.

You may open a public issue asking the maintainers to identify a private
contact, **without describing the vulnerability or sharing sensitive data**.
Wait for the maintainer to confirm the route before sending details. This
request does not itself constitute a private vulnerability report.
